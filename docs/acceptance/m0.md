# M0 人工验收

状态：准备中。以下清单在 M0 实现并通过自动检查后交给用户执行，目前不是通过记录。

## 这次验什么

验证开发环境、员工登录、Twenty 原生只读入口、业务扩展修改入口和管理员改派。客户均为合成数据；本里程碑尚无驾照 OCR、企业办理或邮件发送功能。

## 测试准备

- Twenty 开发地址：`http://localhost:3100`，交付前须再次验证可访问。
- A、B 和管理员账号及测试用密码：交付时保存到忽略且仅本机可读的测试凭据文件，届时在本页补充文件位置；不会写入 Git。
- 使用不同浏览器会话分别登录 A、B、管理员，避免同一浏览器会话互相覆盖。
- 测试报告与已知限制：[M0 验证记录](../reference/m0-validation.md)。自动检查和本表的用户验收分别记录。
